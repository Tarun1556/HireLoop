# HireLoop

HireLoop is an end-to-end recruitment and interview management platform built to streamline candidate tracking, interview scheduling, and feedback management.

---

## 🛠️ Tech Stack

* **Backend:** Java 21, Spring Boot 3, Spring Data JPA, Hibernate, MySQL, Lombok
* **Frontend:** React, Vite, Axios
* **Tooling & API Testing:** Apache Maven, Postman

---

## 📋 Prerequisites

Ensure you have the following installed and running locally:

* **Java Development Kit (JDK):** Version 21 or higher
* **Node.js & npm:** Node.js (v18+) and npm
* **MySQL Server:** Active local instance on port `3306`
